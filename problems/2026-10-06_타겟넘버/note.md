# 타겟 넘버

- 플랫폼: 프로그래머스 (Lv.2, DFS 경우의 수)
- 날짜: 2026-10-06 업로드 (실제 풀이는 출장 중, 정확한 날짜 미기록)

## 접근

- 각 숫자마다 "+로 쓴다 / -로 쓴다" 두 가지 선택이 있으므로, 인덱스를 하나씩 늘려가며 두 갈래로 재귀 분기
- 끝(`idx == len(numbers)`)에 도달했을 때 누적값(`cur`)이 target과 같으면 1, 아니면 0을 반환하고 그대로 합산

## 배운 점 / 실수

- 처음 접하는 "선택 분기형 DFS" 패턴. `dfs(idx+1, 선택A) + dfs(idx+1, 선택B)`처럼 반환값을 그대로 더해서 경우의 수를 세는 틀을 체득함 — 이후 비슷한 유형(각 원소마다 선택지가 있고 조합 수를 세는 문제)에 재사용 가능.
