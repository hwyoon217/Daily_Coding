# 미로 탈출

- 플랫폼: 프로그래머스 (Lv.2, BFS, 159993)
- 날짜: 2026-11-17
- 게임 맵 최단거리 dist 표 방식을 응용한 새 문제. 힌트 받으며 완성 → 나중에 백지 재풀이 필요.

## 접근

- S → L 최단거리 + L → E 최단거리. 둘 중 하나라도 못 가면 -1
- 같은 BFS를 시작점/도착점만 바꿔 두 번 쓰니까 `bfs(start, end)` 함수로 뺌
- 시작점이 `(0,0)` 고정이 아니라서 이중 for문으로 S, L, E 좌표를 먼저 찾음
- 이동 시간을 세는 문제라 `dist[시작] = 0` (게임 맵은 칸 수라서 1)

## 핵심 포인트

**1. BFS 함수로 빼기**
- `start`, `end`는 `(i, j)` 튜플 → `sr, sc = start`로 바로 언패킹 (`.split()`은 문자열 메서드라 튜플엔 에러)
- BFS는 도착점을 노리고 가는 게 아니라 갈 수 있는 모든 칸에 거리를 적음. `end`는 끝나고 **어느 칸 값을 읽을지** 고르는 용도 → `return dist[er][ec]` (while과 같은 들여쓰기)

**2. maps 조건**
- `maps[nr][nc]` = nr번째 줄 문자열의 nc번째 글자 = 다음 칸에 있는 글자
- 지나갈 수 있는 칸: S, O, L, E / 못 가는 칸: X 하나
- `== "O"`로 쓰면 L, E 칸에 못 들어가서 항상 -1 → `!= "X"` (못 가는 하나를 빼는 게 간단)
- 게임 맵은 칸 종류가 0/1 두 개라 `== 1`이 맞았음

**3. 이중 for문 (좌표 찾기)**
- `'S'`(따옴표) = 지도에 적힌 글자 → 찾을 때 `maps[i][j] == 'S'`
- `S`(따옴표 없음) = 그 좌표를 담은 변수 → `S = (i, j)`, 호출할 때 `bfs(S, L)`
- `bfs('S', L)`로 넘기면 `sr, sc = 'S'`에서 ValueError

**4. 마지막 결과 처리**
- 둘 중 하나라도 -1이면 -1, 아니면 합을 `answer`에 **저장**해야 함 (계산만 하고 안 담으면 0 반환)
- 지금은 bfs를 최대 4번 호출. 이 문제(최대 100×100)는 괜찮지만, 큰 문제에선 결과를 변수에 받아두는 게 안전:
  ```python
  a = bfs(S, L)
  b = bfs(L, E)
  ```

## 실수 기록

- 게임 맵 틀을 복붙해서 시작점 `(0,0)` 고정 그대로 둠
- 함수 이름 `dfs`로 정의하고 `bfs`로 호출 → NameError (변수명 불일치 재발)
- 함수 끝 `return` 누락 → None
- `L = ()`, `E = ()` 빈 튜플 → `er, ec = ()`에서 ValueError
- else에서 `answer =` 빠뜨림
- 이름 바꿀 때는 Ctrl+F로 옛 이름 검색해서 0건인지 확인
