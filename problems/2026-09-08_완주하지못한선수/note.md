# 완주하지 못한 선수

- 플랫폼: 프로그래머스 (Lv.1, 해시)
- 소요시간: 약 25분 (v1) + Counter 검색 후 v2 추가

## 접근

- v1: participant, completion을 각각 정렬 후 인덱스별로 비교. 값이 다른 지점의 participant 원소가 답, 끝까지 같으면 마지막 원소가 답 (동명이인이 있어도 정렬하면 같은 이름끼리 붙으므로 안전). O(n log n).
- v2: `Counter(participant) - Counter(completion)`으로 이름별 개수 차이를 구해 남는 이름(완주 못한 선수)을 찾음. O(n).

## 배운 점 / 실수

- `Counter` 뺄셈(`-`)은 일반 dict 뺄셈과 달리 **결과가 0 이하인 key를 자동으로 버림**. 그래서 개수가 같은(완주한) 이름들은 결과에 안 남고, 개수가 남는(완주 못한) 이름만 남음.
- 처음엔 Counter를 몰라서 정렬 비교(v1)로 먼저 풀었음. v1도 정답이고 시간복잡도도 괜찮지만(O(n log n)), 해시 계열 문제 감을 잡는 게 오늘 목표라 Counter로 다시 풀어봄.
