# 의상

- 플랫폼: 프로그래머스 (Lv.2, 해시)
- 예전 문제명은 "위장" (같은 문제, 42578)

## 접근

- 1단계: `defaultdict(int)`로 종류별 옷 개수 세기 (`c_map[cat] += 1`, 신고 결과 받기 v2의 카운트 dict와 같은 패턴)
- 2단계: 종류마다 "그 중 하나 입기 + 안 입기" → `(개수 + 1)`가지. 종류끼리는 독립적으로 고르니까 **곱하기**
- 3단계: 전부 안 입은 경우 1가지 빼기 (최소 1개는 입어야 함)
- 종류 이름은 필요 없고 개수만 쓰므로 `.values()`로 순회

## 배운 점 / 실수

- 첫 풀이는 정답 코드를 보면서 따라 씀 → 같은 날 단계 주석 3줄만 보고 코드는 혼자 다시 써서 통과 (완전 백지 풀이는 아님)
- `+=`와 `*=` 혼동: 더하면 예제 1은 3+2=5로 우연히 맞지만 종류가 3개 이상이면 틀림. 곱셈이니까 `answer`는 **1에서 시작** (0이면 계속 0)
- `{}`는 빈 dict, 빈 set은 `set()`. 콜론이 있으면 dict. `[]`는 list를 만들거나 list/dict에서 값을 꺼낼 때
- `.keys()` 키만 / `.values()` 값만 / `.items()` 둘 다
- `defaultdict(int)`는 처음 보는 키에 0을 넣어줘서 초기화 단계가 필요 없음. import 없이는 `c_map[cat] = c_map.get(cat, 0) + 1`

## 남은 복습 과제

- 며칠 뒤 백지에서 **주석 3줄(세기 → (개수+1) 곱하기 → 1 빼기)부터 직접** 쓰고 코드 채우기
