# 폰켓몬

- 플랫폼: 프로그래머스 (Lv.1, 해시/집합)
- 소요시간: 약 20~30분

## 접근

가지고 있는 nums에서 서로 다른 종류 수(distinct)와 최대로 뽑을 수 있는 개수(N/2) 중 작은 쪽이 답.
1차 시도는 리스트로 중복 체크 후 비교하는 방식으로 통과.

## 배운 점 / 실수

- `x not in list`는 O(n) → 전체 O(n²)가 됨. `set`을 쓰면 O(1) 체크로 O(n)까지 줄어듦. nums 크기가 커질 수 있는 문제에서는 리스트 대신 set/dict로 중복·존재 체크하는 습관 들이기.
- 파이썬 `/`는 항상 float 반환 (`10/2` → `5.0`). 정수 나눗셈이 필요하면 `//` 사용.
